# Архитектура шаблона

Все команды README выполняются из корня репозитория. Дополнительная папка
проекта после `git clone` не нужна.

`agent.py` предоставляет контракт `run(request, ctx) -> AgentResult`.
`src/agent/loop.py` содержит место для реализации агентного цикла.
`src/agent/tools.py` задаёт интерфейс шлюза инструментов. Команда реализует
подключение MCP и преобразование схем в формат выбранного LLM API.

`mcp_server/server.py` создаёт FastMCP-сервер. Декораторы регистрируют две
операции: проверку конфигурации и запуск расчётного сценария.
`mcp_server/simulator/client.py` содержит адаптер к API инженерного ПО.
Пока адаптер не реализован, расчёт завершается явной ошибкой.

Агент и MCP-сервер могут работать на одной машине по stdio. Для HTTP сервер
запускается самостоятельно, клиент использует URL. Установленное инженерное
ПО, лицензия и SDK нужны на стороне адаптера.

## Порядок реализации

1. Описать инженерную операцию, входы, единицы и ожидаемый результат.
2. Задать типизированные схемы вместо общего словаря `parameters`.
3. Реализовать адаптер и проверить его на контрольной копии модели.
4. Проверить MCP-контракт клиентом без LLM.
5. Реализовать разбор запроса и вызов ограниченного набора инструментов.
6. Собирать числа отчёта из ответа инструмента; сохранять версии и `trace_id`.

Для PVT, PROSPER и GAP нужны разные операции. Общий словарь в шаблоне
показывает место передачи параметров; он не заменяет предметную схему проекта.
Критерии сравнения с экспериментом определяются методикой конкретной задачи.
