# Локальный MCP-сервер

Эта папка содержит учебный каркас адаптера к инженерному ПО. Сервер и агент
находятся в одном репозитории, но запускаются как два отдельных процесса.

## Что нужно реализовать

1. Заменить `SimulatorClient.run_case` вызовом OpenServer, Python API или SDK выбранного ПО.
2. Описать отдельный MCP-инструмент для каждой операции симулятора.
3. Указать единицы во входных и выходных схемах.
4. Обработать занятую лицензию, таймаут, отсутствие решения и неверные параметры.
5. Добавить интеграционные тесты на копии модели, которую можно безопасно изменять.

## Запуск

```powershell
pip install -r mcp_server/requirements.txt
python -m mcp_server.server
```

Все команды выполняются из корня репозитория. HTTP для локального клиента:

```powershell
python -m mcp_server.server --http
```

Сервер использует FastMCP 4.1.6. Endpoint: `http://127.0.0.1:8000/mcp`.
Проверка stdio без ручного запуска: `python -m scripts.check_mcp`.

По умолчанию используется транспорт stdio. Для подключения из другой машины
настройте streamable HTTP и защитите endpoint токеном. Colab не может обратиться
к `localhost` компьютера, на котором установлен симулятор.
